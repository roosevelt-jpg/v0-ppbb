# ADR-0300: Echo (VL-227)

- Status: Accepted
- Date: 2026-10-03
- Phase: VL-227 / library Phase 94

## Context

VerbaLab owns its foundation model families. Echo (VerbaLab speech recognition FM) must be a first-class product surface, not a rented third-party model.

## Decision

1. Ship `echo` hub with engine/capabilities/overview/monitoring.
2. Inference routes through VerbaLab Own AI gateway (`VERBALAB_*` endpoints).
3. Do not embed weight binaries in the monorepo; credentials/endpoints configured in deploy env.
4. `ownedModels=true`, `vendorRentalDefault=false`.

## Consequences

- Console `/ echo` and API `/v1/echo/*` are production-wired.
- Live quality depends on deployed VerbaLab model services + eval evidence.
