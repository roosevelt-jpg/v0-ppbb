# Dialect Continuum Engine

Tracks code-switching and dialect drift mid-utterance — Maghrebi Arabic, Pidgin, Sheng, street French — and replies in the right mix.

## APIs

- **Dialect spectrum detection**: `POST /v1/dialect-continuum/detect`
- **Mid-turn drift tracking**: `POST /v1/dialect-continuum/track`
- **Reply-in-mix generation**: `POST /v1/dialect-continuum/reply`
- **Regional continuum map**: `GET /v1/dialect-continuum/map`

Also: `GET /v1/dialect-continuum/engine`, `/overview`, `/activity`, `/monitoring`.

## Console
