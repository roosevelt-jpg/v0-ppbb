# World Language Registry

Parallel to the African Language Registry for Southeast Asia, India / South Asia, Latin America, and the Caribbean.

## Honesty

- `coverageComplete=false` — curated major-language seed, not Ethnologue-complete.
- Country packs, dialects, accents, cultural intelligence, grammar, style, corridors, and Own TTS are seeded for strategic global markets.
- Macro-varieties (`es-latam`, `pt-br-sphere`, `en-sea`, `en-india`, `en-caribbean`, `hi-india`) index regional contact varieties.

## API

- `GET /v1/world-language-registry/engine`
- `GET /v1/world-language-registry/languages`
- `GET /v1/world-language-registry/families`
- `GET /v1/world-language-registry/monitoring`
