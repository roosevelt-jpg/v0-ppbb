# Africa Institutions Hub

How VerbaLab serves **culture**, **sovereignty**, **national pride**, **security**, and **justice** across African institutions.

## Pillars

| Pillar | What VerbaLab contributes |
|---|---|
| Culture | Oral Knowledge OS, Dialect Continuum, intent-preserving dub — languages and heritage stay first-class |
| Sovereignty | Africa residency (`af`/`jnb`), Sovereign Flywheel, compliance attestations, edge offline packs |
| Security | Secure Transcript Alerts, Voice Passport, Civic Voice Seal, Voice Trust Graph |
| Justice | Justice Language Access, Interpreter Mesh, Meeting Transcription |
| Truth | Civic Truth Guard + Civic Voice Seal against deepfakes and viral falsehoods |
