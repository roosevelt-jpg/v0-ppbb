# Intent-Preserving Dub

Dub that preserves joke timing, insult severity, prayer register, gender norms, and power distance — social effect, not word overlap.

## APIs

- **Pragmatic intent analysis**: `POST /v1/intent-preserving-dub/analyze`
- **Intent-preserving dub render**: `POST /v1/intent-preserving-dub/dub`
- **Social-effect score**: `POST /v1/intent-preserving-dub/score`
- **Register / culture profiles**: `GET /v1/intent-preserving-dub/profiles`

Also: `GET /v1/intent-preserving-dub/engine`, `/overview`, `/activity`, `/monitoring`.
