# VerbaLab deploy credentials

Platform code is wired. You add secrets at deploy time. **VerbaLab model keys are generated by you inside VerbaLab** — they are not rented from OpenAI/ElevenLabs/Google.

## 1. VerbaLab model keys (you create these)

These authenticate your Own AI model services.

| Kind | Prefix | Where |
| --- | --- | --- |
| Serving key | `vmod_live_` / `vmod_test_` | Console **Model keys** or `POST /v1/model-keys` |
| Platform root | `vmod_root_` | `POST /v1/model-keys/platform-root` → set as `VERBALAB_MODEL_API_KEY` |

### Quick start (local)

1. Sign in to the console → **Model keys** (`/model-keys`).
2. Click **Mint platform root**.
3. Copy the secret into `apps/api/.env`:

```bash
VERBALAB_MODEL_API_KEY=vmod_root_…
VERBALAB_MODEL_BASE_URL=https://models.your-domain.com/v1
# optional per modality:
# VERBALAB_MT_URL= VERBALAB_STT_URL= VERBALAB_TTS_URL=
# VERBALAB_CHAT_URL= VERBALAB_EMBED_URL= VERBALAB_OCR_URL= VERBALAB_CLONE_URL=
```

4. Put the **same** `VERBALAB_MODEL_API_KEY` on your model-serving pods so the API can call them.

Or generate offline:

```bash
pnpm --dir apps/api exec tsx scripts/mint-model-key.ts
```

### Product API keys (customers)

Separate from model keys: `vl_live_` / `vl_test_` on **API keys** (`/keys`) for `POST /v1/translate` etc.

## 2. How to get third-party deploy credentials

### Clerk (auth)

1. Create an app at [clerk.com](https://clerk.com) → Dashboard.
2. Copy **Publishable key** → `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`
3. Copy **Secret key** → `CLERK_SECRET_KEY`
4. Set sign-in URLs (`NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in`, etc.)

Dev already supports test keys / `/dev-login` bypass when configured.

### Stripe (billing)

1. [dashboard.stripe.com](https://dashboard.stripe.com) → Developers → API keys.
2. **Secret key** → `STRIPE_SECRET_KEY`
3. Create a Product/Price for Pro → `STRIPE_PRICE_ID_PRO`
4. Webhooks → endpoint `https://<api>/v1/billing/webhook` → `STRIPE_WEBHOOK_SECRET`
5. (Optional) Connect for creator payouts.

### Fly.io (hosting)

1. Install CLI: `fly auth login`
2. `fly tokens create deploy` → `FLY_API_TOKEN`
3. Set app secrets: `fly secrets set VERBALAB_MODEL_API_KEY=… STRIPE_SECRET_KEY=…`

### Resend (email)

1. [resend.com](https://resend.com) → API Keys → `RESEND_API_KEY`

### Optional legacy vendors

Only if `VERBALAB_ALLOW_VENDOR_FALLBACK=1`:

- Google Cloud Translation / Vision
- OpenAI
- ElevenLabs

Not required for the VerbaLab Own AI product path.
