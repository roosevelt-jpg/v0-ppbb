# Fusion

VerbaLab-owned model family for **Multimodal fusion FM**.

## Endpoints

- `GET /v1/fusion/engine`
- `GET /v1/fusion/capabilities`
- `GET /v1/fusion/overview` (auth)
- `GET /v1/fusion/monitoring`

## Runtime

Served via VerbaLab Own AI (`VERBALAB_MODEL_BASE_URL` / modality URL + `VERBALAB_MODEL_API_KEY`).
Set `VERBALAB_OWN_AI_FIXTURE=1` for local/CI.
