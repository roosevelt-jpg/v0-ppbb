# Interpreter Mesh

One live session, many listeners — each hears a different language/dialect/register from a shared semantic backbone.

## APIs

- **Mesh session create**: `POST /v1/interpreter-mesh/sessions`
- **Listener dialect channel**: `POST /v1/interpreter-mesh/listen`
- **Speaker utterance ingest**: `POST /v1/interpreter-mesh/broadcast`
- **Shared semantic backbone**: `GET /v1/interpreter-mesh/backbone`

Also: `GET /v1/interpreter-mesh/engine`, `/overview`, `/activity`, `/monitoring`.
